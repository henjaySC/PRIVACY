1. About the Game

Echoes of the Past: A 3D Quest-Based Philippine History Game is an educational mobile game that introduces selected topics in Philippine history through 3D exploration, historical characters, quests, historical locations, artifact information, and quizzes.

2. Information We Collect

The game is designed to let players explore and complete activities without creating an account or submitting personal information directly to the development team. Game progress, such as quest progress and collection status, is designed to be saved locally on the device.

The game does not provide cloud saves, multiplayer gameplay, online chat, or social networking features. However, the device platform or any third-party software included in the published build may process technical information under its own terms. The developer should verify the final app build before release and update this section to disclose any analytics, advertising, crash reporting, or other data collection that is enabled.

3. Local Storage and Game Progress

Game settings and progress may be stored on the player's device so the game can remember local progress and preferences. This information is not intended to be sent to the developer's servers. Removing the application or clearing its app data may delete locally stored progress.
